\lnPitch{
  In the past, uplifting a legacy codebase used to be a risky and expensive endeavour. Many are the technical debt backlogs that never got priority. The economics for dealing with \hs{technical debt} have changed. Dramatically.
  \par
  A legacy uplift that would traditionally have been a 12–18 month, high-risk engineering project was completed in \hs{three weeks} of part-time work for roughly \$4,000 in AI costs.
  \where{Adam Tornhill \href{https://codescene.com/blog/case-study-refactoring-at-scale-with-agents}{on CodeScene blog}; Sep 24, 2026}
  \boom{Rewrite}{Revive}
  }

\lnPitch{
  In practice, reviews of agent-generated code become \hs{rubber-stamps}: the human approves because the code looks correct, because the tests pass, and because the \hs{cognitive cost} of genuine scrutiny is prohibitive. The assurance that review is supposed to provide is illusory.
  \where{Martin Monperrus \href{https://arxiv.org/html/2606.13175v1}{on arXiv}; Jun 11, 2026}
  \boom{Attention}{Distraction}
  }

\lnPitch{
  The cost of code improvements has dropped so low that we can afford a \hs{zero tolerance} attitude to minor code smells and inconveniences.
